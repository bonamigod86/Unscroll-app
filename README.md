# Unscroll-app

Anti-dopamine screen blocker for Android. Adds a friction barrier when you open distracting apps — hold, type a stoic quote or complete a 30-second breath to unlock.

Kotlin · Jetpack Compose · Play Billing · Superwall-ready

## Build

Open in Android Studio (JDK 17) or:

```bash
./gradlew :app:assembleDebug
```
